# AI Campus Assistant

## Project Title

AI Campus Assistant

AI Campus Assistant is an AI-powered academic support platform designed to assist students, teachers, and administrators in managing academic activities efficiently. The system combines campus management functionalities with Artificial Intelligence to provide academic assistance, routine management, assignment tracking, study planning, note summarization, quiz generation, and intelligent question answering.

- Manage Academic Notices

### Teacher Module

- Student Authentication
- View Class Routine
- View Exam Routine
- View Assignments

### AI Features

#### AI Chat Assistant

Students can ask academic and campus-related questions and receive intelligent responses.

**Examples:**
- What is Artificial Intelligence?
- Explain Database Normalization.
- Help me understand Object-Oriented Programming.

#### Rule-Based Academic Query System

Students can retrieve academic information directly from the system database.

**Examples:**
- What is the exam routine for Section 7C?
- Show upcoming assignments for Section 3B.
- What CTs are scheduled this week?

#### AI Study Planner

Generates personalized study schedules based on exam dates, subjects, and available study time.

**Example:**
- Create a 7-day study plan for DBMS.

#### AI Assignment Helper

Provides guidance, explanations, and suggestions to help students complete assignments.

#### AI Quiz Generator

Automatically generates:
- Multiple Choice Questions (MCQ)
- True/False Questions
- Short Questions

#### AI Note Summarizer

Summarizes lecture notes, documents, and academic content into concise key points.

### Notification System

- Assignment Notifications

- Routine Update Notifications
